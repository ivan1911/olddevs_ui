# Security policy

## Supported versions

Security fixes are released for the latest major version of `@olddevs/ui`, currently 4.x. Earlier major versions don't receive fixes. If you are on one of them, upgrade first.

## Reporting a vulnerability

Don't report vulnerabilities in public issues, pull requests or discussions.

Use GitHub's private vulnerability reporting instead:

1. Open the [Security tab](https://github.com/ivan1911/olddevs_ui/security) of the repository.
2. Choose **Report a vulnerability**.
3. Describe the problem: the affected version, what an attacker can do and the steps to reproduce it. A minimal example helps.

Only we see the report until a fix is available.

## What to expect

- We will acknowledge your report.
- We will confirm whether we can reproduce the problem and keep you informed as we work on it.
- A confirmed vulnerability is fixed in a patch release of the latest major version. The release notes describe the fix, and we credit you if you want to be named.

This is a small project maintained by one person, so we don't promise response or fix times.

## Scope

This policy covers the code in this repository and the `@olddevs/ui` package on npm. Vulnerabilities in dependencies, such as React, `react-aria-components` or `lucide-react`, should be reported to those projects.
