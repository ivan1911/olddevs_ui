# Словарь `@olddevs/ui`

Термины кита. Одно понятие — одно слово: синоним из соседней системы (плагин, сервис, нода,
библиотека) заводит второй смысл, и разойдутся они молча. Если у слова два смысла, оба
получают составное имя («примитив палитры», «слой оверлея»), а голое слово остаётся за одним
из них.

Общие термины в тексте пишутся как обычные слова, со строчной: «потребитель», «роль»,
«витрина». Термины Редактора — с большой буквы («Блок», «Панель»): их легко спутать с
обиходным словом, и заглавная показывает, что слово значит ровно то, что в таблице.

Новый термин попадает сюда в том же изменении, где появился. Словарь лежит в пакете, а не в
репозитории документации, потому что меняется вместе с кодом; сайт документации показывает
его из закреплённой версии кита.

Имена пропсов — отдельный словарь:
[семантический словарь пропсов](conventions.md#семантический-словарь-пропсов).

## Кит и потребитель

| Термин                  | Значение                                                                                                                                                                                                                                    | Не путать с                                                                                                                                    |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| **Кит**                 | Дизайн-система `@olddevs/ui`: токены, темы, доступные компоненты и их документация                                                                                                                                                          | Пакетом: тот — то, как кит доставляется. Библиотекой: так кит не называется, слово занято сторонними зависимостями (react-aria, Radix, Tiptap) |
| **Пакет**               | npm-артефакт `@olddevs/ui` со входами и `styles.css`; публикуется в npm                                                                                                                                                                     | Китом: у одного кита один пакет, но кит — ещё и решения, витрина и макет                                                                       |

Всё, что не вход, — не публичный API                                  | Путём в `src/`: он может смениться в любой версии                                                                                              |
| **Публичный контракт**  | Экспорты входов, их типы, документированное поведение и `styles.css`                                                                                                                                                                        | Исходниками: они доказывают поведение, но импортировать их нельзя                                                                              |

Доменные тексты, запросы, словари статусов и раскладка экрана принадлежат ему, а не киту                                                                                                         | Компонентом кита                                                                                                                               |

Не заменяется ручной разметкой                                                                                                      | Примитивом палитры — цветовым токеном слоя 1                                                                                                   |

Компонент лежит в той же категории в `docs/components/` и в `src/components/`                           | Семьёй компонентов: категория собирает несколько семей                                                                                         |
| **Ядро**                | Компоненты, для которых обязателен полный обряд проверки: поведенческие тесты, покрытие классов, axe, снимки (ADR-0014)                                                                                                                     | Периферией                                                                                                                                     |
| **Периферия**           | Обёртки над готовым поведением `react-aria-components`: для них хватает сокращённого набора проверок                                                                                                                                        | Ядром                                                                                                                                          |
| **Каталог сообщений**   | Строки интерфейса кита, которые `UiProvider` отдаёт компонентам: готовые каталоги — входы `locales/ru` и `locales/en`, без провайдера работает английский фолбэк в коде. Проп компонента переопределяет строку точечно ([i18n.md](i18n.md)) | Каталогом компонентов. Текстами экрана: их кит не переводит                                                                                    |

| **Гейт**       | Одна автоматическая проверка, которая роняет прогон: гейт контраста (`npm run contrast`), гейт i18n, `format:check`                                         | Воротами: гейт — одна проверка из их списка                                                      |

| **Зеркало**    | Файл Figma `Olddevs UI DS`: повторяет кит, но источником правды не является; при расхождении меняется Figma (ADR-0015)                                      | Макетом, по которому пишут код: исключение — только компонент, которого в коде ещё нет           |
| **Волна**      | Набор изменений, который планировался и выпускался вместе; ADR и комментарии ссылаются на номер волны                                                       | Версией пакета: номер волны с номером релиза не связан                                           |

## Токены и темы

| Термин                    | Значение                                                                                                                                                                          | Не путать с                                                       |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| **Слой токенов**          | Одна из четырёх ступеней цепочки цвета: примитивы палитры → роли → компонентные токены → бренд. Слой ниже не знает о слое выше ([theming.md](theming.md#четыре-слоя))             | Слоем оверлея — ступенью z-index                                  |
| **Примитив палитры**      | Токен слоя 1 `--od-<семья>-<шаг>`: цвет как значение, без роли и без темы. Потребитель его не переопределяет                                                                      | Примитивом — компонентом кита                                     |
| **Семья цвета**           | Ряд примитивов палитры одного оттенка: нейтрали `slate`, `cloud`, `navy` и семь тоновых. Шаг внутри семьи растёт по светлоте, 1 — самый тёмный                                    | Семьёй компонентов                                                |
| **Роль**                  | Токен слоя 2: что чем красится — `--surface-*`, `--text-*`, `--accent*`, тона. Тема меняет только роли                                                                            | Классом Tailwind: тот стоит на роли, а не наоборот                |
| **Компонентный токен**    | Токен слоя 3 — отличие одной семьи компонентов от общей роли (`--overlay-scrim`, `--topbar-bg`). Список закрытый                                                                  | Ролью                                                             |
| **Тема**                  | Набор значений ролей на `<html data-theme>`: `dark` (по умолчанию), `light`, `dim`                                                                                                | Акцентом: это независимая ось. Листом Редактора                   |
| **Акцент**                | Цвет действия и выделения на `<html data-accent>`: `blue` (по умолчанию), `violet`                                                                                                | Тоном `accent`: тот берёт значение акцента, но это ось компонента |
| **Бренд**                 | Слой 4: блок бренда `[data-brand]` поверх ролей и компонентных токенов — своя палитра потребителя одним блоком CSS                                                                | Темой: бренд работает в любой теме                                |
| **Поверхность**           | Роль фона: `--surface-app`, `--surface-panel`, `--surface-elevated` и соседние; в компонентах — алиасы `--bg-0…4`                                                                 | Пропом `surface` Редактора: тот выбирает Лист                     |
| **Инверсная поверхность** | Группа ролей для плашки прямо на Документе, которая отличается от него знаком, а не шагом: светлая в `dark` и `dim`, тёмная в `light` (`--surface-inverse`, `--text-on-inverse`)  | Поверхностью `--surface-contrast`: та — шаг той же темы           |
| **Тон**                   | Смысловой цвет из словаря `Tone`: `neutral`, `accent`, `success`, `warning`, `danger`. У тона две роли: `--<тон>` — заливка под текстом, `--<тон>-strong` — текст и рамка на фоне | Вариантом (`variant`): тот отвечает, насколько тон заметен        |
| **Плотность**             | Умолчание вертикального ритма таблиц через `UiProvider`: `comfortable` или `compact`; проп таблицы его перекрывает                                                                | Размером (`size`): тот — ось одного компонента                    |
| **Шкала движения**        | Закрытые ступени длительности (`--duration-fast` … `--duration-slow`) и три кривые (`--ease-standard`, `-enter`, `-exit`). Имена по роли, а не по значению (ADR-0047)             | Шагом семьи цвета                                                 |

## Оси пропсов

| Термин             | Значение                                                                                                                          | Не путать с                                                                          |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| **Ось**            | Независимый проп с закрытым набором значений, общим на весь кит: `size`, `tone`, `variant`. Ось включается явным пропом           | Состоянием (`selected`, `disabled`, `loading`): оно булево и называется положительно |
| **Подача**         | Ось `variant`: насколько заметен тон — `solid`, `soft`, `outline`, `ghost`, один набор на весь кит                                | Формой варианта (`appearance`)                                                       |
| **Форма варианта** | Проп `appearance` вне осей: другая форма того же компонента — `appearance="card"` даёт рамку, индикатор и описание внутри подписи | Подачей: та меняет заметность тона, а не форму                                       |

Смысл каждой оси и пропсы вне осей (`appearance`, `active`, `level`) — в
[семантическом словаре пропсов](conventions.md#семантический-словарь-пропсов).

## Взаимодействие

Слова, которыми страницы описывают, как компонентом управляют мышью, пальцем и клавиатурой.

| Термин                   | Значение                                                                                                                                        | Не путать с                                                                 |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| **Зона нажатия**         | Область, которая принимает нажатие; бывает больше видимого контрола. Нижний порог — WCAG 2.5.8, 24 × 24 px                                      | Размером (`size`): тот меняет вид, а зона может остаться прежней            |
| **Ручка перетаскивания** | Отдельная кнопка строки, за которую строку переносят мышью, пальцем или с клавиатуры: `SortableList`, `EditableList`                            | Ручкой Блока Редактора и ручкой высоты                                      |
| **Ручка высоты**         | Полоса у нижнего края поля с `resizable`, за которую меняют его высоту; с клавиатуры — как ползунок                                             | Ручкой перетаскивания                                                       |
| **Трафарет маски**       | Маска, которую пустое поле `MaskedInput` показывает целиком (`__.__.____`) и которую ввод заменяет символ за символом. Украшение: `aria-hidden` | Скелетом Редактора — видом поля до Готовности                               |
| **Элемент коллекции**    | Одна запись `items` у компонента-коллекции: пункт меню, строка списка, узел дерева                                                              | Элементом разметки (DOM): так и пишем — «элемент разметки»                  |
| **Недоступный**          | Состояние `disabled`: действие сейчас выполнить нельзя, контрол приглушён и нажатие не срабатывает                                              | Только для чтения (`readOnly`): значение видно и копируется, но не меняется |
| **Выборка**              | Записи, которые остались после фильтров; считает её потребитель                                                                                 | Выделением                                                                  |
| **Выделение**            | Записи, которые отметил пользователь (`selectedKeys`)                                                                                           | Выборкой: фильтр сужает выборку, а выделение — то, что отмечено внутри неё  |

## Слои поверх

| Термин           | Значение                                                                                                                                                                                               | Не путать с                                                                      |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------- |
| **Оверлей**      | Элемент кита поверх страницы: окно, ящик, меню, поповер, подсказка, список подсказок                                                                                                                   | Порталом: оверлей может лежать и в DOM владельца, как плавающая Панель Редактора |
| **Слой оверлея** | Именованная ступень z-index из `OVERLAY_LAYER`: `modal` — затемнение и окно, `alert` — подтверждение над окном, `popover` — меню, поповеры, списки. Числа z-index вне этой шкалы не пишутся (ADR-0041) | Слоем токенов                                                                    |
| **Стек Escape**  | Стек открытых оверлеев кита (`src/lib/overlay-layer.ts`), общий для оверлеев на Radix и на react-aria: Escape обрабатывает только верхний, вложенные закрываются по одному                             | Слоем оверлея: верхний в стеке определяется положением в документе, а не z-index |

## Компоненты в тексте

Как компонент называется по-русски в прозе. Слова после «Не пишем:» в тексте не употребляются: читатель
ищет по одному слову.

| Термин                     | Значение                                                                                                                                        | Не путать с                                                                                             |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| **Окно**                   | `Dialog`: модальная поверхность с затемнением                                                                                                   | Ящиком. Окном браузера — его так и называем: «окно браузера». Не пишем: модалка                         |
| **Ящик**                   | `Drawer`: модальная панель, которая выезжает от края                                                                                            | Окном. Не пишем: шторка, выдвижная панель                                                               |
| **Поповер**                | `Popover`: немодальная панель у кнопки, которая её открыла                                                                                      | Подсказкой: в той нет интерактива. Не пишем: попап                                                      |
| **Подсказка**              | `Tooltip`: короткий текст при наведении и фокусе                                                                                                | Поповером. Не пишем: тултип                                                                             |
| **Пояснение**              | `hint` у `FormField` и соседних полей: текст под полем, который помогает его заполнить                                                          | Подсказкой (`Tooltip`) и плейсхолдером. Не пишем: подсказка поля                                        |
| **Плейсхолдер**            | `placeholder`: пример значения, который виден в пустом поле и исчезает при вводе                                                                | Пояснением и подсказкой. Не пишем: подсказка в поле                                                     |
| **Тост**                   | Глобальное уведомление `toast()` в `Toaster`                                                                                                    | Сообщением поля Редактора: то привязано к полю                                                          |
| **Флажок**                 | `Checkbox`: выбор «да / нет» в наборе                                                                                                           | Переключателем `Toggle` (`role="switch"`): одно булево свойство, а не выбор в наборе. Не пишем: чекбокс |
| **Полоса над таблицей**    | Слот `toolbar` у `DataTable`, обычно `TableToolbar`                                                                                             | Панелью Редактора и примитивом `Toolbar`. Не пишем: тулбар                                              |
| **Раскрыватель**           | Кнопка, которая раскрывает меню: правая часть `SplitButton`, кнопка `Menu`                                                                      | Поповером: тот — сама раскрывшаяся панель. Не пишем: disclosure, стрелка-меню                           |
| **Сегментированный выбор** | `Segmented`: ряд кнопок, из которых выбрана ровно одна                                                                                          | Вкладками `Tabs` (те переключают панели) и `ToggleGroup` (там выбрано ноль или несколько)               |
| **Тег**                    | `Tag` в `TagGroup` и `TagInput`: компактный элемент с текстом и необязательной кнопкой удаления                                                 | Меткой Редактора (`Mark`) и подписью поля. Не пишем: таг                                                |
| **Кнопка закрытия**        | Кнопка с иконкой «×», которая закрывает окно, ящик, поповер или уведомление; у поля поиска — **кнопка очистки**                                 | Кнопкой «Отмена». Не пишем: крестик                                                                     |
| **Свод сочетаний**         | `ShortcutsHelp`: окно со списком сочетаний клавиш                                                                                               | Справочником Редактора: тот открывается из Панели и описывает сочетания Редактора                       |
| **Мегаменю**               | `MegaMenu`: Столбец категорий и Полка наведённой Категории — каталог в духе Amazon                                                              | `Menu`: тот для команд, а не для навигации. Не пишем: мега-дропдаун                                     |
| **Категория**              | `MegaMenuCategory`: строка Столбца с подписью, иконкой и своей Полкой                                                                           | Пунктом меню (`MenuItem`)                                                                               |
| **Столбец категорий**      | Вертикальный список Категорий Мегаменю                                                                                                          | `SideNav`: тот раскрывает ветки на месте                                                                |
| **Полка**                  | Область рядом со Столбцом с содержимым открытой Категории: колонки ссылок, промо. До 4.3.0 — «Витрина»; проп ширины по-прежнему `showcaseWidth` | Витриной — это Storybook кита; Панелью Редактора и поповером                                            |
| **Прицел**                 | Отложенная смена Категории, пока курсор идёт наискосок к открытой Полке                                                                         | Задержкой открытия: прямое наведение Прицел не тормозит                                                 |

## Редактор

Термины `RichTextEditor` и `RichTextView` (вход `@olddevs/ui/editor`). Здесь особенно легко
взять слово из соседнего редактора (плагин, сервис, нода) — оно заводит второй смысл.

| Термин                     | Значение                                                                                                                                                                                                                                                                                                                                           | Не путать с                                                                                                                                                                                                 |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Редактор**               | `RichTextEditor` — поле ввода форматированного текста                                                                                                                                                                                                                                                                                              | Редактором кода: его в ките нет, показ кода — `CodeView`                                                                                                                                                    |
| **Просмотр**               | `RichTextView` — только чтение сохранённого Документа                                                                                                                                                                                                                                                                                              | `readOnly`-режимом Редактора: тот держит движок, Просмотр — нет                                                                                                                                             |
| **Оглавление**             | `RichTextToc`: список заголовков Документа рядом с Просмотром или Редактором. Свёрнуто — полоса штрихов, раскрыто — список, клик по пункту ведёт к заголовку                                                                                                                                                                                       | `Heading` кита и навигацией сайта документации                                                                                                                                                              |
| **Документ**               | Значение Редактора: HTML-строка, ограниченная Схемой                                                                                                                                                                                                                                                                                               | JSON-деревом ProseMirror в движке — оно внутреннее; наружу оно выходит только JSON-конвертом                                                                                                                |
