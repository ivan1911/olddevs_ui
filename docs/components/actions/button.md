# Button

## Кратко для AI

`Button` запускает действие. Для перехода используйте настоящую ссылку через `asChild`, а не `onClick` с маршрутизацией. По умолчанию это `type="button"`, поэтому внутри формы он не отправляет её случайно.

## Когда использовать

- Пользователь должен выполнить действие: сохранить, открыть диалог, удалить, повторить запрос.
- Нужен общий набор `variant`, `tone`, `size`, `disabled` и фокусной индикации.
- Действие — навигация: передайте одну ссылку как `children` вместе с `asChild`.

## Когда не использовать

- Для выбора одного режима используйте `Segmented`; для независимого набора фильтров — `ToggleGroup`.
- Для переключения булевого состояния с ролью switch используйте `Toggle`.
- Для ссылки, которой не нужен вид кнопки, используйте `Link`.

## Минимальный пример

```tsx
<Button tone="accent" variant="solid" onClick={save}>
  Сохранить
</Button>

<Button asChild variant="soft">
  <a href="/campaigns">К кампаниям</a>
</Button>
```

## Public API

- `variant`, `tone`, `size` определяют внешний вид; умолчания — `soft`, `neutral`, `md`.
- Ступеней размера четыре: `xs`, `sm`, `md`, `lg`. `xs` — 20 пикселей, и
  заведена она под кнопку-иконку в строке списка: `sm` даёт 30 при 20 под
  содержимое, и строка на 32 растягивается до 42. Подпись в `xs` не
  предполагается — берите вместе с `iconOnly`. Зона нажатия у `xs` всё равно
  24×24: её расширяет псевдоэлемент, потому что 20×20 не проходит
  WCAG 2.5.8, а увеличить саму кнопку — значит вернуть растянутую строку.
- `icon` добавляет иконку; с `iconOnly` подпись не рисуется. У icon-only кнопки доступное имя обязательно: `aria-label` или `title`. Сама иконка целью попадания не является (`pointer-events: none`): иначе `event.target` у щелчка в рисунок — `<svg>`, а не кнопка, и всякий, кто разбирает цель щелчка, ошибается. Живой случай — строка `EditableList` с действием: react-aria проверяет цель, не обходя предков, и щелчок по иконке запускал и кнопку, и действие строки.
- `selected` ставит `aria-pressed`; он нужен только нажатой **кнопке**, у ссылки (`asChild`) его нет.
- `loading` — идёт отправка: индикатор занимает слот иконки, кнопка не нажимается, состояние объявляется через `aria-busy`. Отдельный `disabled` не пишите: он включается сам. У кнопки без иконки слот появляется на время отправки, и подпись сдвигается; если у кнопки бывает `loading`, дайте ей иконку сразу. Индикатор декоративен и в доступное имя кнопки не входит.
- `asChild` передаёт стиль, props и ref единственному дочернему элементу. Для ссылки `disabled` становится `aria-disabled`, отключает pointer-события и исключает потомка из обхода табуляции (`tabIndex={-1}`) — в том числе если тот задал `tabIndex` сам: решает компонент, иначе выключенная ссылка оставалась достижимой с клавиатуры. `selected` не переносится, поскольку `aria-pressed` недопустим для link.

## Доступность и семантика

- Обычная кнопка активируется Space и Enter; ссылка при `asChild` — Enter, как и положено ссылке.
- Не вкладывайте интерактивные элементы в `children`.
