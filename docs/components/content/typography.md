# Typography: `Text`, `Heading`, `Link`

## Кратко для AI

Используйте `Heading` для структуры документа, `Text` для абзацев и служебных
строк, `Link` для навигации. Не заменяйте их `div` и ручными Tailwind-классами:
эти компоненты уже несут семантику, визуальную шкалу и доступность.

## Когда использовать

- `Heading` — когда текст начинает логический раздел. Всегда задавайте
  `level`; это уровень в оглавлении, а не выбор размера.
- `Text` — для текста, который не заголовок: абзаца, подписи,
  описания, вторичного или служебного сообщения.
- `Link` — для перехода к адресу или маршруту. Для действия без навигации
  используйте `Button`.
- `numeric="tabular"` у `Text` и `Heading` — когда число меняется на месте или
  стоит колонкой: таймер, счётчик, обратный отсчёт, сводка. У пропорциональных
  цифр строка с тем же числом знаков меняет ширину и сдвигает соседей в той же строке.

## Когда не использовать

- Не выбирайте `Heading` только ради крупного шрифта: сохраните правильный
  уровень и при необходимости передайте `size`.
- Не применяйте `Text level` как уровень заголовка: у `Text` это лишь
  приглушённость цвета. Для заголовка нужен `Heading`.
- Не используйте `Link` для мутации данных, открытия диалога или отправки
  формы; это кнопочное действие.
- Не ставьте `Link external` вместо `target="_blank"`: первый добавляет
  иконку, но не меняет способ открытия.
- Не задавайте `numeric="tabular"` всему тексту подряд: цифры равной ширины
  шире пропорциональных и в обычном абзаце читаются хуже. Проп `numeric` нужен там, где
  цифры сравниваются между собой или меняются на месте.
- Не берите `numeric` вместо `font-mono`, когда нужен именно моноширинный
  шрифт (код, хеш): проп меняет только ширину цифр, гарнитура не меняется.

`font-mono` — системный моноширинный стек (`ui-monospace`, SF Mono, Menlo,
Consolas, Liberation Mono): кит своих файлов шрифта не загружает. Свой шрифт кода
потребитель подставляет переменной `--font-code` — так же, как `--font-inter`
для основного (например, `variable: "--font-code"` у `next/font`).

## Минимальные примеры

```tsx
import { Heading, Link, Text } from "@olddevs/ui";

<Heading level={2}>Расписание</Heading>
<Text level={2}>Выберите время публикации.</Text>
<Text as="span" size="sm" tone="danger">Ошибка сохранения</Text>
<Link href="/campaigns">К кампаниям</Link>
<Text as="span" numeric="tabular">12:00</Text>
```

```tsx
<Link external href="https://example.com" target="_blank">
  Внешняя документация
</Link>
```

## Public API

### `Text`

| Prop       | Назначение и ограничения                                                                                           |
| ---------- | ------------------------------------------------------------------------------------------------------------------ |
| `size`     | Ступень `caption`, `xs`, `sm`, `md` (по умолчанию) или `lg`. Это размер, не семантика.                             |
| `level`    | Приглушённость `1`–`3`; по умолчанию `1`. Работает только с `tone="neutral"`.                                      |
| `tone`     | Семантический цвет; при ненейтральном тоне он заменяет цвет от `level`, а не смешивается с ним.                    |
| `weight`   | `regular` (по умолчанию), `medium` или `bold`.                                                                     |
| `numeric`  | `tabular` — цифры равной ширины. Умолчания нет: обычный текст остаётся с пропорциональными.                        |
| `truncate` | `true` — одна строка с многоточием; положительное число — столько строк. `0` безопасно трактуется как одна строка. |
| `as`       | `p` (по умолчанию), `span` или `div`; меняет только HTML-тег, не вид.                                              |

### `Heading`

| Prop      | Назначение и ограничения                                                                                                                |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `level`   | Обязательный логический уровень `1`–`4`; по умолчанию рендерится соответствующий `h1`…`h4`. Не пропускайте уровни в структуре страницы. |
| `size`    | Независимый от уровня кегль `md`, `lg`, `xl`, `2xl`. Если не задан, берётся из `level`.                                                 |
| `as`      | Явный тег `h1`…`h6`, если место в разметке требует другого тега; сам уровень и его размер от этого не меняются.                         |
| `numeric` | `tabular` — цифры равной ширины, та же ось, что у `Text`: для крупного числа сводки, которое пересчитывается на месте.                  |

### `Link`

| Prop              | Назначение и ограничения                                                                                                                                                                                                                                                                                                |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `variant`         | `inline` (по умолчанию, всегда подчёркнут), `standalone` или `quiet`. Используйте `inline` внутри текста; `quiet` — для вторичной навигации.                                                                                                                                                                            |
| `tone`            | Семантический тон; по умолчанию `accent`. У `quiet` тон проявляется при наведении.                                                                                                                                                                                                                                      |
| `external`        | Добавляет скрытую от скринридера иконку внешней ссылки; не устанавливает `target`.                                                                                                                                                                                                                                      |
| `as`              | Тег или компонент роутера, например `next/link`. Пропсы сохраняют тип выбранного компонента.                                                                                                                                                                                                                            |
| `target="_blank"` | Компонент добавляет скрытое пояснение о новой вкладке и, если свой `rel` не передан, `rel="noopener noreferrer"`.                                                                                                                                                                                                       |
| `href`            | Исполняемые схемы отбрасываются: ссылка рисуется без адреса. Это `javascript:`, `vbscript:` и исполняемые типы `data:` (`text/html`, `application/xhtml+xml`, `image/svg+xml`). Остальное проходит как есть — включая собственные схемы приложения (`slack://`) и неисполняемый `data:` (картинка, CSV под `download`). |

## Доступность и семантика

- `Heading level` формирует доступное оглавление. Визуальный размер не должен
  заставлять менять семантический уровень.
- Вариант `Link inline` постоянно подчёркнут: цвет — не единственный
  признак ссылки внутри текста.
- У `Link target="_blank"` доступное имя дополняется сообщением о новой
  вкладке. Переданный `rel` компонент сохраняет.
- Не подменяйте видимый текст компонентом `VisuallyHidden`: скрытый текст дополняет уже
  понятный элемент, но не компенсирует отсутствующую понятную подпись.

## Антипаттерны

```tsx
// Плохо: h4 выбран ради маленького кегля после h2.
<Heading level={4}>Фильтры</Heading>

// Хорошо: структура остаётся h3, размер отделён.
<Heading level={3} size="md">Фильтры</Heading>

// Плохо: утилита навешена на семантический элемент мимо шкалы.
<Text as="span">
  <time dateTime={`PT${seconds}S`} className="tabular-nums">{formatDuration(seconds)}</time>
</Text>

// Хорошо: ось у компонента, `time` остаётся чистым — свойство наследуется.
<Text as="span" numeric="tabular">
  <time dateTime={`PT${seconds}S`}>{formatDuration(seconds)}</time>
</Text>

// Плохо: ссылка запускает действие.
<Link onClick={deleteCampaign}>Удалить</Link>

// Хорошо: действие — кнопка.
<Button tone="danger" onPress={deleteCampaign}>Удалить</Button>
```
