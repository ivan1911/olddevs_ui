# Справочник `@olddevs/ui`

Этот справочник — контракт для разработчиков и AI-агентов, которые используют
публичный API пакета. Исходник правды для экспортов —
[`src/index.ts`](../src/index.ts); исходники компонентов, тесты и Storybook
подтверждают поведенческие утверждения на страницах.

   не похожий внешний вид.

## Правила для AI

- **Начните с `llms.txt`** в корне пакета: это указатель на все страницы
  справочника с описанием каждой. Он собирается из `docs/` скриптом, то есть
  отстать от них не может.
- Импортируйте только публичные входы пакета (список — в [словаре](glossary.md)); не
  импортируйте файлы из `src/` пакета напрямую.
- До чтения API страницы прочитайте «Когда использовать» и «Когда не
  использовать»: компоненты с похожим видом могут выражать разные действия.
- Не заменяйте семантический компонент ручной разметкой, если пакет уже
  предоставляет подходящий публичный экспорт.
- Соблюдайте описанный в справочнике контракт controlled/uncontrolled и требования
  к подписи (`label`), фокусу и Escape. Внешний вид на скриншоте этих контрактов
  не заменяет.
- Документируйте изменение публичного API в том же изменении, что и код; полные
  правила сопровождения лежат в `CLAUDE.md` репозитория кита — в пакет он не
  едет, и ссылки на него здесь нет намеренно.

## Область действия

Документы находятся в репозитории пакета и **с 3.8.0 едут вместе с ним в
реестр**: `docs/` целиком плюс указатель `llms.txt` в корне пакета
(ADR-0044).
Агенту в чужом репозитории больше не нужны ни ссылка на этот репозиторий, ни
доступ к нему: справочник лежит в `node_modules/@olddevs/ui/docs/` и той самой
версии, которая установлена, — а не той, что сейчас в `main`.

У кита есть публичный сайт документации, но указатель на него не ссылается:
ссылок вида `https://…` в нём нет, все пути относительные и ведут внутрь пакета.

**Чего в пакете нет — это ADR.** Страницы справочника ссылаются на решения
номером, `ADR-NNNN`, множество раз, но сами решения ведутся отдельно от кода
и в пакет не входят. Справочник от этого читается
полностью — контракт, API и доступность описаны на самих страницах, — но
«почему решено так» остаётся в репозитории решений. Цена принята осознанно
(ADR-0044); если довод нужен, спросите в issues репозитория.
