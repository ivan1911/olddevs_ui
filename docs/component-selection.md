# Как выбрать компонент

Выбирайте по смыслу действия и состоянию, а не по форме, которую проще собрать.
Если правило ниже не подходит, откройте каталог компонентов и страницу ближайшего кандидата
до написания JSX.

| Задача                                                   | Используйте                         | Не используйте вместо этого            | Причина                                                                                                                                  |
| -------------------------------------------------------- | ----------------------------------- | -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Выбрать значение из известного конечного набора          | `Select`                            | `Combobox`                             | `Select` не допускает нового значения; поиск только фильтрует набор.                                                                     |
| Ввести значение со списком вариантов или разрешить новое | `Combobox`                          | `Select`                               | `Combobox` поддерживает свободный ввод, когда это разрешено контрактом.                                                                  |
| Выбрать ровно один режим                                 | `Segmented`                         | `ToggleGroup`                          | У режима всегда есть значение; пустое состояние недопустимо.                                                                             |
| Включить ноль, одно или несколько независимых условий    | `ToggleGroup`                       | `Segmented`                            | Нулевой набор для фильтров и настроек законен.                                                                                           |
| Подтвердить удаление или другое опасное действие         | `ConfirmDialog`                     | `Dialog`                               | `alertdialog`, явный destructive action и безопасная начальная точка фокуса.                                                             |
| Показать обычное модальное содержимое или форму          | `Dialog`                            | `ConfirmDialog`                        | Обычное окно не должно изображать критическое подтверждение.                                                                             |
| Показать свод горячих клавиш экрана                      | `ShortcutsHelp`                     | `Dialog` с россыпью `Kbd` / `Keyboard` | Группы с именами и озвучка сочетания («Ctrl плюс K») уже в компоненте; `Keyboard` — экранная клавиатура для ввода, а не сочетание.       |
| Показать краткий результат завершённой операции          | `toast` + `Toaster`                 | `Alert`                                | Тост временный и не занимает постоянное место на странице.                                                                               |
| Показать постоянное важное сообщение в контексте         | `Alert`                             | `toast`                                | Пользователь должен видеть сообщение, пока оно актуально.                                                                                |
| Показать состояние сущности                              | `StatusBadge`                       | `Badge`                                | Статус — закрытый семантический набор, его тон сообщает значение.                                                                        |
| Показать количество                                      | `Badge`                             | `StatusBadge`                          | Счётчик сообщает «сколько», но не жизненный цикл сущности.                                                                               |
| Перейти по URL                                           | `Link` или `Button asChild` с `<a>` | `Button onClick`                       | Настоящая ссылка сохраняет открытие в новой вкладке, копирование адреса и корректную роль.                                               |
| Дать дополнительное краткое пояснение                    | `Tooltip` / `HelpTooltip`           | скрытый текст без имени                | Подсказка не заменяет подпись и основной контент.                                                                                        |
| Показать превью сущности по наведению на ссылку или имя  | `HoverCard`                         | `Tooltip` / `Popover`                  | Карточка с разметкой открывается наведением и клавиатурным фокусом; на тач-устройствах её нет, поэтому всё важное должно быть и без неё. |
| Сообщить о состоянии всего приложения                    | `Banner`                            | `Alert`                                | `Alert` описывает состояние места на странице; баннер переживает навигацию.                                                              |
| Показать судьбу выбранных файлов                         | `UploadQueue`                       | `FileDropzone`                         | Область даёт файлы, очередь показывает, что с ними стало.                                                                                |
| Показать ленту произошедших событий                      | `NotificationList`                  | `Timeline`                             | У ленты порядок задаёт время, и есть действия; у `Timeline` порядок задаёт процесс.                                                      |
| Показать плитку с превью и действиями                    | `MediaCard`                         | `Card`                                 | У плитки главное — превью с сохранением пропорций, оверлей и выбор.                                                                      |
| Дать пользователю задать порядок                         | `SortableList`                      | `Table` с сортировкой                  | В таблице порядок вычисляется, здесь — назначается человеком.                                                                            |
| Показать сотни превью                                    | `VirtualGrid`                       | обычный CSS-грид                       | В DOM живут только видимые ячейки; высоту контейнера задаёт потребитель.                                                                 |
| Скопировать значение в буфер                             | `CopyButton`                        | самодельная кнопка с иконкой           | Результат объявляется, а отказ буфера виден, а не проглатывается.                                                                        |
| Обрезать длинный текст                                   | `Truncate`                          | `text-overflow` руками                 | Подсказка появляется только у текста, который действительно обрезан, и доступна с клавиатуры.                                            |

## Правило минимального компонента

Не создавайте новый локальный примитив, пока нужная семантика уже есть в
`@olddevs/ui`. Но не переносите доменные данные в пакет: например, словарь статусов,
тексты конкретного продукта и раскладка страницы принадлежат потребителю.

## Если компонента нет

1. Проверьте [каталог компонентов](components/index.md) и публичные icon exports.
2. Соберите доменную композицию из существующих примитивов, если это лишь
   раскладка или текст конкретного экрана.
3. Предлагайте новый примитив, только когда повторяются семантика, API и
   требования доступности, а не одна CSS-комбинация.
